# Gyanendra Gautam — Ethan-style GitHub Portfolio

This is a static GitHub Pages portfolio recreated from the supplied Ethan template screenshots, adapted for a video editor.

## Publish free on GitHub Pages
1. Create a public repository named `YOURUSERNAME.github.io`.
2. Upload `index.html` and the `assets` folder.
3. Go to Settings → Pages.
4. Choose Deploy from a branch → `main` → `/ (root)`.
5. Save. Your site will appear at `https://YOURUSERNAME.github.io/`.

## Replace before publishing
- Replace `assets/profile.jpg` if desired.
- Replace the four project cards with your real thumbnails and video links.
- Replace `your@email.com`.
- Replace the showreel placeholder with your real video.
- The contact form is visual only until connected to a form backend/service.
